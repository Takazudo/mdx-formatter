# Formatting Rules

mdx-formatter is an AST-based formatter — it parses your markdown/MDX into an abstract syntax tree, applies formatting rules, and serializes it back. This means formatting is structural, not text-based, so it won't break your content.

This section describes how each type of content is formatted.
