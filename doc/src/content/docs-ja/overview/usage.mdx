## mdx-formatter とは？

mdx-formatter は、Markdown と MDX のソースを整形する Node.js 向けのツールです。Rust エンジンを使用し、元のソースをできるだけ保ちながら、読みやすい形式に整えます。

## 主な機能

- Markdown・MDX・JSX 構文の整形
- 日本語を含む CJK テキストの扱い
- Docusaurus の admonition 構文と GFM テーブルの保持
- CLI、Node.js API、ブラウザ向け WASM パッケージ
