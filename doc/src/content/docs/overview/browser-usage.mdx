# Browser Usage

## WASM Package (Recommended)

For browser environments, install the WASM package:

```bash
npm install @takazudo/mdx-formatter-wasm
```

### Usage

```javascript
import init, { format, format_with_defaults } from "@takazudo/mdx-formatter-wasm";

// Initialize the WASM module first
await init();

// Format with default settings
const formatted = format_with_defaults("# Hello\nSome text");

// Format with custom settings (JSON string)
const settings = JSON.stringify({
  addEmptyLineBetweenElements: { enabled: true },
  formatMultiLineJsx: { indentSize: 4 },
});
const formatted2 = format("# Hello\nSome text", settings);
```

The WASM module provides the same Rust formatting engine that powers the Node.js package, compiled to WebAssembly for browser use. See the [Playground](/docs/playground) for a live example.

## Node.js Browser Export

The `./browser` subpath export re-exports the same `format()` function as the main entry point. Since the formatting engine is a Rust napi module, this export requires a Node.js runtime — it is suitable for Electron or similar Node-backed environments, but **not for pure browser use** (use the WASM package instead).

```typescript
import { format } from "@takazudo/mdx-formatter/browser";

const formatted = await format(content);
```

## Detecting MDX

The `detectMdx` function is available from both the main and browser exports:

```typescript
import { detectMdx } from "@takazudo/mdx-formatter/browser";

if (detectMdx(content)) {
  console.log("Content has MDX syntax");
}
```

## Limitations

Config file loading (`.mdx-formatter.json`) is not supported in browser/WASM mode because it requires Node.js file system access. Pass settings directly to the format function instead.
