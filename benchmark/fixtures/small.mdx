# Getting Started with MDX

MDX lets you use JSX in your markdown content. You can import components, such as interactive charts or alerts, and embed them within your content.

## Installation

Install the required packages using your preferred package manager:

```bash
npm install @mdx-js/mdx
```

This will set up the basic MDX processing pipeline for your project.

## Basic Usage

Once installed, you can start writing MDX files. The syntax is a combination of markdown and JSX, making it easy to create rich, interactive documentation.

Here is a simple example of an MDX component in action. The `Alert` component displays a styled message to the user.

<Alert type="info">This is an informational message rendered inside MDX.</Alert>
