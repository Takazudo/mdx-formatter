### 型安全なイベントハンドラー

イベントハンドラーの型を正確に定義することで、実行時エラーを防ぎます。

```tsx
type FormFieldName = 'username' | 'email' | 'password' | 'confirmPassword';

interface FormState {
  values: Record<FormFieldName, string>;
  errors: Partial<Record<FormFieldName, string>>;
  touched: Partial<Record<FormFieldName, boolean>>;
}

function useForm(initialValues: Record<FormFieldName, string>) {
  const [state, setState] = useState<FormState>({
    values: initialValues,
    errors: {},
    touched: {},
  });

  const handleChange = (field: FormFieldName) => (e: React.ChangeEvent<HTMLInputElement>) => {
    setState((prev) => ({
      ...prev,
      values: { ...prev.values, [field]: e.target.value },
      touched: { ...prev.touched, [field]: true },
    }));
  };

  const validate = (): boolean => {
    const errors: Partial<Record<FormFieldName, string>> = {};

    if (!state.values.username) {
      errors.username = 'ユーザー名は必須です';
    }
    if (!state.values.email.includes('@')) {
      errors.email = '有効なメールアドレスを入力してください';
    }
    if (state.values.password.length < 8) {
      errors.password = 'パスワードは8文字以上で入力してください';
    }
    if (state.values.password !== state.values.confirmPassword) {
      errors.confirmPassword = 'パスワードが一致しません';
    }

    setState((prev) => ({ ...prev, errors }));
    return Object.keys(errors).length === 0;
  };

  return { state, handleChange, validate };
}
```

### レンダープロップス

レンダープロップスは、コンポーネント間でロジックを共有するための柔軟なパターンです。

```tsx
interface DataFetcherProps<T> {
  url: string;
  children: (data: {
    data: T | null;
    loading: boolean;
    error: Error | null;
    refetch: () => void;
  }) => React.ReactNode;
}

function DataFetcher<T>({ url, children }: DataFetcherProps<T>) {
  const [data, setData] = useState<T | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  const fetchData = useCallback(async () => {
    setLoading(true);
    setError(null);
    try {
      const response = await fetch(url);
      const json = await response.json();
      setData(json);
    } catch (err) {
      setError(err instanceof Error ? err : new Error('Unknown error'));
    } finally {
      setLoading(false);
    }
  }, [url]);

  useEffect(() => {
    fetchData();
  }, [fetchData]);

  return <>{children({ data, loading, error, refetch: fetchData })}</>;
}
```

## テスト戦略

テストは品質を保証するために不可欠です。ここでは、フロントエンドのテスト戦略について説明します。

### テストピラミッド

テストは以下の階層で構成します。

| レベル               | 対象              | ツール          | 実行速度 |
| -------------------- | ----------------- | --------------- | -------- |
| ユニットテスト       | 関数、フック      | Vitest          | 高速     |
| コンポーネントテスト | UIコンポーネント  | Testing Library | 中速     |
| 統合テスト           | 画面遷移、API連携 | Playwright      | 低速     |
| E2Eテスト            | ユーザーシナリオ  | Playwright      | 最低速   |

### ユニットテストの書き方

```tsx
import { describe, it, expect } from 'vitest';
import { formatCurrency, parseQueryString, debounce } from './utils';

describe('formatCurrency', () => {
  it('should format positive numbers', () => {
    expect(formatCurrency(1234)).toBe('¥1,234');
    expect(formatCurrency(0)).toBe('¥0');
  });

  it('should handle negative numbers', () => {
    expect(formatCurrency(-500)).toBe('-¥500');
  });

  it('should handle decimal values', () => {
    expect(formatCurrency(1234.56)).toBe('¥1,234.56');
  });
});

describe('parseQueryString', () => {
  it('should parse simple query strings', () => {
    const result = parseQueryString('?page=1&sort=name');
    expect(result).toEqual({ page: '1', sort: 'name' });
  });

  it('should handle empty query strings', () => {
    expect(parseQueryString('')).toEqual({});
    expect(parseQueryString('?')).toEqual({});
  });

  it('should decode URI components', () => {
    const result = parseQueryString('?name=%E7%94%B0%E4%B8%AD');
    expect(result).toEqual({ name: '田中' });
  });
});
```

### コンポーネントテスト

```tsx
import { render, screen, fireEvent } from '@testing-library/react';
import { describe, it, expect, vi } from 'vitest';
import { SearchInput } from './SearchInput';

describe('SearchInput', () => {
  it('should render with placeholder', () => {
    render(<SearchInput placeholder="検索..." onSearch={vi.fn()} />);
    expect(screen.getByPlaceholderText('検索...')).toBeInTheDocument();
  });

  it('should call onSearch when form is submitted', () => {
    const onSearch = vi.fn();
    render(<SearchInput placeholder="検索..." onSearch={onSearch} />);

    const input = screen.getByPlaceholderText('検索...');
    fireEvent.change(input, { target: { value: 'テスト' } });
    fireEvent.submit(input.closest('form')!);

    expect(onSearch).toHaveBeenCalledWith('テスト');
  });

  it('should clear input when clear button is clicked', () => {
    render(<SearchInput placeholder="検索..." onSearch={vi.fn()} />);

    const input = screen.getByPlaceholderText('検索...');
    fireEvent.change(input, { target: { value: 'テスト' } });

    const clearButton = screen.getByRole('button', { name: 'クリア' });
    fireEvent.click(clearButton);

    expect(input).toHaveValue('');
  });
});
```

## パフォーマンス最適化

### メモ化の戦略

React のメモ化APIを適切に使用することで、不要な再レンダリングを防ぎます。

```tsx
import { memo, useMemo, useCallback } from 'react';

interface UserListProps {
  users: User[];
  onSelect: (userId: string) => void;
  filter: string;
}

const UserList = memo(function UserList({ users, onSelect, filter }: UserListProps) {
  const filteredUsers = useMemo(
    () => users.filter((user) => user.name.includes(filter)),
    [users, filter],
  );

  const handleSelect = useCallback(
    (userId: string) => {
      onSelect(userId);
    },
    [onSelect],
  );

  return (
    <ul>
      {filteredUsers.map((user) => (
        <li key={user.id} onClick={() => handleSelect(user.id)}>
          {user.name}
        </li>
      ))}
    </ul>
  );
});
```

### キーボードナビゲーション

すべてのインタラクティブな要素がキーボードで操作可能であることを確認します。

```tsx
function DropdownMenu({ items }: { items: MenuItem[] }) {
  const [isOpen, setIsOpen] = useState(false);
  const [focusedIndex, setFocusedIndex] = useState(-1);
  const menuRef = useRef<HTMLUListElement>(null);

  const handleKeyDown = (e: React.KeyboardEvent) => {
    switch (e.key) {
      case 'ArrowDown':
        e.preventDefault();
        setFocusedIndex((prev) => Math.min(prev + 1, items.length - 1));
        break;
      case 'ArrowUp':
        e.preventDefault();
        setFocusedIndex((prev) => Math.max(prev - 1, 0));
        break;
      case 'Escape':
        setIsOpen(false);
        setFocusedIndex(-1);
        break;
      case 'Enter':
      case ' ':
        if (focusedIndex >= 0) {
          items[focusedIndex].onClick();
          setIsOpen(false);
        }
        break;
    }
  };

  return (
    <div onKeyDown={handleKeyDown}>
      <button aria-expanded={isOpen} aria-haspopup="true" onClick={() => setIsOpen(!isOpen)}>
        メニュー
      </button>
      {isOpen && (
        <ul ref={menuRef} role="menu">
          {items.map((item, index) => (
            <li
              key={item.id}
              role="menuitem"
              tabIndex={index === focusedIndex ? 0 : -1}
              className={index === focusedIndex ? 'focused' : ''}
            >
              {item.label}
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}
```
